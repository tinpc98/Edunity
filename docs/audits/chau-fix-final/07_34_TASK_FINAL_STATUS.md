# 07. 34-TASK FINAL STATUS MATRIX — TASK FIX-FINAL (CHÂU)

Tài liệu này thay thế cách gọi chung `"DONE"` bằng đúng **bộ 7 trạng thái kỹ thuật trung thực** đối với toàn bộ **34 tasks thuộc Châu (`Phase 0 → Phase 6`)**:

1. `PASS_VERIFIED` — Phạm vi backend/API/DB tự khép kín, chạy thật đạt 100% trên ReplSet/Jest.
2. `PASS_CHÂU_SCOPE_ONLY` — Phần của Châu hoàn tất & kiểm chứng 100%, nhưng luồng E2E liên module chưa nối phần của Tin/Bảo.
3. `PARTIAL` — Chức năng cốt lõi đạt, còn thiếu phần phụ thuộc liên nhóm trên runtime thật (ví dụ browser upload/CORS ở phía Bảo).
4. `FAIL` — Kiểm thử thất bại do lỗi code hoặc sai yêu cầu nghiệp vụ.
5. `BLOCKED_EXTERNAL` — Bị chặn **fail-closed (`503` / fallback an toàn)** vì dependency bên ngoài (`TEA-12`, `AID-08`, `DEP-INFRA-01`) chưa triển khai trên hệ thống.
6. `NOT_VERIFIED` — Chưa chạy kiểm chứng thực tế.
7. `NOT_IMPLEMENTED` — Chưa triển khai.
