## Rollback Procedure
- Hủy toàn bộ thay đổi chưa commit của file bất kỳ: `git checkout -- <path>`
- Xóa file mới chưa tracked (sau khi rà soát): `Remove-Item <path>`
- Khôi phục toàn bộ working tree về HEAD `4656799`: `git reset --hard 4656799` (CHỈ dùng khi người dùng xác nhận)
